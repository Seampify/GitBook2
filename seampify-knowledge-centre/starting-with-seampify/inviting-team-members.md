# Inviting Team Members

**Team Settings** allows you to create user accounts for your employees, granting either full control or limited access based on their roles.

{% hint style="warning" %}
To add an agent you must first [create a roles](../seampifys-modules/settings/workspace-settings/roles-and-permissions.md#create-a-role) and [teams](../seampifys-modules/settings/workspace-settings/team-members/teams.md).
{% endhint %}

## Add Member

1. Navigate to **Settings > Teams**
2. Click the " **+ Add Member** " button

<figure><img src="../.gitbook/assets/Invite Team Member (1).png" alt=""><figcaption></figcaption></figure>

3. Create Team Member

<figure><img src="../.gitbook/assets/Invite Team Member (2).png" alt=""><figcaption></figcaption></figure>

This will open the create user modal with the following fields,

* Full Name
* Email
* Phone Number
* Channels
* Skills
* Notes
* Max Chat Assignment
* Teams
* Roles

Simply add the information, and once you've added all click **Save**. As soon as you save the Team member it will appear on the page like the below list.

<figure><img src="../.gitbook/assets/Invite Team Member (3).png" alt=""><figcaption></figcaption></figure>
