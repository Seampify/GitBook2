# My Workspace

The **My Workspace** module in Seampify provides a centralized workspace for managing daily activities, scheduling appointments, organizing tasks, and tracking customer follow-ups.

My Workspace consists of two main sections:

| **Section** | **Description**                                                                |
| ----------- | ------------------------------------------------------------------------------ |
| Calendar    | Manage appointments, meetings, scheduled events, and booking availability.     |
| Tasks       | Create and manage tasks, sales activities, reminders, and customer follow-ups. |

## Accessing My Workspace

1. Log in to your Seampify account.
2. Click **My Workspace** on the left-hand navigation menu.
3. Select **Calendar** or **Tasks** from the submenu.
