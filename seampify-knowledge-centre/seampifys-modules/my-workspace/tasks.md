# Tasks

The **Tasks & Follow-ups** section allows businesses to create, organize, and monitor sales activities, customer follow-ups, reminders, and daily responsibilities.

This helps users track outstanding activities and ensure important customer follow-ups are not overlooked.

## Prerequisites

Before creating a new task, ensure that your organization has configured at least one **Task Type**.

Task Types are customizable categories that allow businesses to organize tasks according to their operational requirements.

<figure><img src="../../.gitbook/assets/tasks (6).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Task Type is a mandatory field when creating a task. If no Task Types have been configured, navigate to **Settings → Tasks** to create one before proceeding.
{% endhint %}

### Configuring Task Types

1. Navigate to **Settings** from the left-hand navigation menu.
2. Under **Workspace**, select **Tasks**.
3. Click **+ Add Task Type** at the top-right corner.
4. Complete the required information.
5. Click **Create Task Type** to save.

<figure><img src="../../.gitbook/assets/tasks (7).png" alt=""><figcaption></figcaption></figure>

## Tasks Overview

Navigate to **My Workspace → Tasks** to access the Tasks & Follow-ups dashboard.

## Task Summary

The top section of the Tasks dashboard displays four key indicators that provide a quick overview of your task activities.

<figure><img src="../../.gitbook/assets/tasks (3).png" alt=""><figcaption></figcaption></figure>

| **Metric** | **Description**                                                       |
| ---------- | --------------------------------------------------------------------- |
| Today      | Number of tasks due on the current date.                              |
| Overdue    | Number of outstanding tasks that have passed their due date and time. |
| Pending    | Number of tasks that have not been completed.                         |
| Completed  | Number of tasks marked as completed.                                  |

## Search and Filter Tasks

The Tasks dashboard provides several filtering options to help users locate and organize their activities.

| **Filter**     | **Description**                                |
| -------------- | ---------------------------------------------- |
| Search Tasks   | Search for a specific task using its title.    |
| All Priorities | Filter tasks based on their assigned priority. |
| All Types      | Filter tasks based on their task type.         |

### Task Category Tabs

Users can also filter tasks using the available category tabs.

| **Tab**   | **Description**                                        |
| --------- | ------------------------------------------------------ |
| All Tasks | View tasks across available categories.                |
| Today     | View tasks due today.                                  |
| Tomorrow  | View tasks due tomorrow.                               |
| This Week | View tasks scheduled for the current week.             |
| Overdue   | View incomplete tasks that have passed their due date. |
| Completed | View tasks that have been completed.                   |

## Creating a New Task

To create a new task:

1. Navigate to **My Workspace → Tasks**.
2. Click **+ Add Task** at the top-right corner.
3. Complete the **Create New Task** form.
4. Click **Create Task** to save the task.
