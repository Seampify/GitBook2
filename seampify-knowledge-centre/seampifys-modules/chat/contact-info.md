# Contact Information Panel

The Contact Information Panel is located on the right-hand side of the Inbox. It allows agents to access customer information and manage customer-related activities without leaving the conversation.

<figure><img src="../../.gitbook/assets/Contact Info (1).png" alt=""><figcaption></figcaption></figure>

### Contact, CRM and Task

The panel provides three main tabs.

| **Tab** | **Description**                                                |
| ------- | -------------------------------------------------------------- |
| Contact | View and manage customer information and conversation details. |
| CRM     | Access customer-related CRM information.                       |
| Task    | Access tasks associated with the customer.                     |

### Contact Details

The Contact tab displays information associated with the selected customer, including:

* Contact name.
* Communication channel.
* Associated labels.
* Contact phone number.
* Primary communication channel.
* Technical identifiers, where available.

Click the **Edit** icon to access contact editing options.

### Communication Channels

Displays the communication channels associated with the selected contact.

Click **+ Add** to add another communication channel to the contact.

### Contact Information Tabs

| **Tab**  | **Description**                                                   |
| -------- | ----------------------------------------------------------------- |
| Overview | Displays general contact and conversation management information. |
| Media    | Access media associated with the conversation.                    |
| Notes    | View customer-related notes.                                      |
| History  | Access historical records associated with the contact.            |

{% hint style="info" %}
Some channel might not have the Phone Number section.
{% endhint %}

{% hint style="warning" %}
If a contact is using a [WhatsApp Username](../../useful-guides/whatsapp-api-business-account/phone-number-quality-rating/), their phone number will not be visible due to Meta's privacy policy.
{% endhint %}
