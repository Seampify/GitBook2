# Inbox

The **Seampify Inbox** is a centralized communication hub that allows businesses to manage customer conversations across connected messaging channels. It enables agents to respond to enquiries, assign conversations, manage customer information, track conversation statuses, and collaborate with team members from a single interface.

## Understanding the Inbox Interface

The Inbox is divided into four main sections:

<figure><img src="../../.gitbook/assets/Inbox (2).png" alt=""><figcaption></figcaption></figure>

| **Section**               | **Description**                                                        |
| ------------------------- | ---------------------------------------------------------------------- |
| Inbox Filters             | Organize and filter customer conversations based on specific criteria. |
| Conversation List         | Displays customer conversations and their latest messages.             |
| Conversation Panel        | View conversation history, send messages, and manage conversations.    |
| Contact Information Panel | View customer information, assignments, CRM records, and tasks.        |

## Managing a Customer Conversation

A typical customer conversation management process is illustrated below.

{% stepper %}
{% step %}
### **Receive customer enquiry**

Customer sends a message through a connected communication channel.
{% endstep %}

{% step %}
### **Open conversation**

Agent selects the conversation from the Inbox.
{% endstep %}

{% step %}
### **Assign conversation**

Assign the conversation to the appropriate agent or department.
{% endstep %}

{% step %}
### **Respond to customer**

Reply to the enquiry and provide the necessary assistance.
{% endstep %}

{% step %}
### **Update customer information**

Add relevant labels, notes, CRM information, or follow-up activities.
{% endstep %}

{% step %}
### **Update conversation status**

Mark the conversation as pending or closed, depending on its progress.
{% endstep %}
{% endstepper %}

<details>

<summary>Benefits of the Inbox</summary>

* Centralize customer communications across connected channels.
* Improve agent collaboration and conversation management.
* Organize customer conversations using filters and labels.
* Monitor unread, unassigned, and pending conversations.
* Manage customer information, CRM records, and tasks.
* Track customer communication and call history.
* Improve customer service efficiency and follow-up management.

</details>
