# Developer & Billing

The **Developer & Billing** category provides access to communication channel settings, developer tools, integrations, and billing information.

| Section         | Description                                                   |
| --------------- | ------------------------------------------------------------- |
| Channels        | Access settings for connected communication channels.         |
| Developers      | Access developer-related configurations.                      |
| Integrations    | Access integration settings for connecting external services. |
| Usage & Billing | View and manage usage and billing-related information.        |
