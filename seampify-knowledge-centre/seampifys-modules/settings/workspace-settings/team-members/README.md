# Team Members

## Add Member

1. Navigate to **Settings > Teams**
2. Click the " **+ Add Member** " button

<figure><img src="../../../../.gitbook/assets/Invite Team Member (1).png" alt=""><figcaption></figcaption></figure>

3. Create Team Member

<figure><img src="../../../../.gitbook/assets/Invite Team Member (2).png" alt=""><figcaption></figcaption></figure>

This will open the create user modal with the following fields,

* Full Name
* Email
* Phone Number
* Channels
* Skills
* Notes
* Max Chat Assignment
* Teams
* Roles

Simply add the information, and once you've added all click **Save**. As soon as you save the Team member it will appear on the page like the below list.

<figure><img src="../../../../.gitbook/assets/Invite Team Member (3).png" alt=""><figcaption></figcaption></figure>

## Activate/Deactivate a User

At Seampify, you get the option to activate/deactivate an agent's account whenever needed. Whether for permanent/temporary reasons.

<figure><img src="../../../../.gitbook/assets/Teams (3).png" alt=""><figcaption></figcaption></figure>

Click on the status bar to toggle between Active and Inactive status.

## Search for a Agent <a href="#search-for-a-team-member" id="search-for-a-team-member"></a>

To quickly find out an agent's account, you can use the Search option.

<figure><img src="../../../../.gitbook/assets/Teams (4).png" alt=""><figcaption></figcaption></figure>

Simply enter the name of the member in the Search bar. Alternatively, you can filter the agents by their assigned channels or status.

## Resetting password for an Agent's Account

If an agent forgets their password for their Seampify account, the Organization Admin can easily reset it for them. Simply click the three dots under and select **Change** **Password**.

<figure><img src="../../../../.gitbook/assets/Teams (5).png" alt=""><figcaption></figcaption></figure>

Then, enter a new password and click **Save**.

<figure><img src="../../../../.gitbook/assets/Teams (7).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
This step is only able to perform by the Organization Admin. If you wish to reset the password for Organization Admin, kindly contact Seampify's customer support.
{% endhint %}
