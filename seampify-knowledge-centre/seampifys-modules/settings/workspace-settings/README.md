# Workspace Settings

The **Workspace** category allows businesses to manage organization configurations and internal operational settings.

| **Section**         | **Description**                                                                                                        |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Organization        | Access organization settings.                                                                                          |
| CRM                 | Configure Lead Lifecycle Stages and Deal Pipeline Stages, including stage names, percentages, colors, and arrangement. |
| Contacts            | Access contact-related settings.                                                                                       |
| Tasks               | Create and manage custom Task Types, including names, descriptions, icons, and colors.                                 |
| Team Members        | Access team member management settings.                                                                                |
| Roles & Permissions | Manage user roles and permissions within the organization.                                                             |

{% hint style="info" %}
**Note:** CRM pipeline stages and Task Types are customizable according to your organization's business requirements.
{% endhint %}
