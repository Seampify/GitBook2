# Ecommerce

The **Ecommerce** module in Seampify allows businesses to manage their online stores, product categories, product catalogs, customers, and orders from a centralized platform.

The module consists of six main sections:

| **Section** | **Description**                                                             |
| ----------- | --------------------------------------------------------------------------- |
| Overview    | View a summary of your eCommerce setup and access quick management actions. |
| Stores      | Create and manage stores associated with your communication channels.       |
| Categories  | Organize products into categories and subcategories.                        |
| Products    | Manage product information, pricing, inventory, and publishing status.      |
| Customers   | Manage eCommerce customers linked to WhatsApp contacts.                     |
| Orders      | View and manage customer orders and their statuses.                         |

## Accessing Ecommerce

1. Log in to your Seampify account.
2. Click **Ecommerce** on the left-hand navigation menu.
3. Select the relevant tab to access its features.

## Stores

The **Stores** section allows businesses to create and manage eCommerce stores tied to their communication channels.

<figure><img src="../.gitbook/assets/ecom (2).png" alt=""><figcaption></figcaption></figure>

### Store Information

| **Column**    | **Description**                                           |
| ------------- | --------------------------------------------------------- |
| Name          | Name of the store.                                        |
| Channels      | Communication channels associated with the store.         |
| Currency      | Currency used by the store, such as MYR.                  |
| Tax %         | Tax percentage configured for the store.                  |
| Tax ID        | Tax identification information, where applicable.         |
| Support Email | Customer support email address associated with the store. |
| Status        | Current store status, such as Active.                     |
| Meta Catalog  | Displays the Meta catalog connection option or status.    |

### Creating a Store

1. Navigate to **Ecommerce → Stores**.
2. Click **+ Create Store**.
3. Complete the store configuration.
4. Save the store.

The **Connect to Meta** option is also available for connecting a store to a Meta catalog.

## Categories

The **Categories** section allows businesses to organize products into categories and subcategories for easier product management.

### Category Information

| **Column**  | **Description**                                              |
| ----------- | ------------------------------------------------------------ |
| Name        | Name of the product category.                                |
| Parent      | Parent category associated with the category, if applicable. |
| Description | Description of the category.                                 |
| Actions     | Additional category management options.                      |

### Creating a Category

1. Navigate to **Ecommerce → Categories**.
2. Select the relevant store.
3. Click **+ Create Category**.
4. Enter the required category information.
5. Save the category.

Categories can be used when organizing products within the selected store.

## Products

The **Products** section allows businesses to manage their product catalog, including product information, pricing, inventory, and publishing status.

<figure><img src="../.gitbook/assets/ecom (4).png" alt=""><figcaption></figcaption></figure>

### Product Management Options

| **Option**              | **Description**                                 |
| ----------------------- | ----------------------------------------------- |
| Import CSV              | Import product information using a CSV file.    |
| Import XLSX             | Import product information using an Excel file. |
| Import from Integration | Import products from an available integration.  |
| Add Product             | Manually create a new product.                  |

### Product Filters

Users can filter the product catalog using the following options:

| **Filter** | **Description**                                             |
| ---------- | ----------------------------------------------------------- |
| Store      | Display products associated with a selected store.          |
| Category   | Filter products by category.                                |
| Min Price  | Set the minimum product price.                              |
| Max Price  | Set the maximum product price.                              |
| Stock      | Filter products based on stock availability.                |
| Publish    | Filter products based on publishing status.                 |
| Meta Sync  | Filter products based on their Meta synchronization status. |

### Product Information

| **Column** | **Description**                                        |
| ---------- | ------------------------------------------------------ |
| Product    | Product name and image.                                |
| SKU        | Unique stock keeping unit associated with the product. |
| Price      | Selling price of the product.                          |
| Stock      | Available product quantity.                            |
| Category   | Category associated with the product.                  |
| Status     | Current product status, such as Active.                |
| Publish    | Product publishing status, such as Published.          |
| Meta       | Meta synchronization information.                      |
| Actions    | Additional product management options.                 |

**Note:** Product currency is inherited from the store configuration.

## Customers

The **Customers** section allows businesses to view and manage eCommerce customers linked to contacts through their WhatsApp identity.

<figure><img src="../.gitbook/assets/ecom (5).png" alt=""><figcaption></figcaption></figure>

### Customer Information

| **Column**   | **Description**                                              |
| ------------ | ------------------------------------------------------------ |
| Name         | Customer's name.                                             |
| WhatsApp     | Customer's WhatsApp phone number.                            |
| Email        | Customer's email address, if available.                      |
| Status       | Current customer status, such as Active.                     |
| Block Reason | Reason associated with a blocked customer, where applicable. |
| Actions      | Additional customer management options.                      |

### Searching Customers

Users can search for customers using:

* Customer name.
* WhatsApp phone number.

### Creating a Customer

1. Navigate to **Ecommerce → Customers**.
2. Click **+ Create Customer**.
3. Complete the customer information.
4. Save the customer.

## Orders

The **Orders** section allows businesses to view and manage customer orders.

<figure><img src="../.gitbook/assets/ecom (6).png" alt=""><figcaption></figcaption></figure>

### Searching and Filtering Orders

| **Filter**    | **Description**                                            |
| ------------- | ---------------------------------------------------------- |
| Search Orders | Search for orders using the order number or customer name. |
| Store         | Filter orders based on the selected store.                 |

### Order Information

| **Column** | **Description**                               |
| ---------- | --------------------------------------------- |
| Order #    | Unique order identification number.           |
| Customer   | Customer associated with the order.           |
| Store      | Store associated with the order.              |
| Placed     | Date and time the order was placed.           |
| Items      | Number of items in the order.                 |
| Total      | Total order amount.                           |
| Status     | Current order status, such as Pending.        |
| Return     | Return-related information, where applicable. |
| View       | Open the order details.                       |

### Viewing Order Details

To view an order:

1. Navigate to **Ecommerce → Orders**.
2. Locate the order using the search bar or store filter.
3. Click **View**.
4. The order details panel will appear.

<figure><img src="../.gitbook/assets/ecom (7).png" alt=""><figcaption></figcaption></figure>

### Order Details

The order details panel displays the following information:

| **Section**          | **Description**                                                                 |
| -------------------- | ------------------------------------------------------------------------------- |
| Order Number         | Unique identifier of the order.                                                 |
| Order Status         | Current status of the order.                                                    |
| Placed Date          | Date and time the order was placed.                                             |
| Items                | Products included in the order, including product details, quantity, and price. |
| Subtotal             | Total product amount before additional charges and discounts.                   |
| Discount             | Discount applied to the order.                                                  |
| Tax                  | Tax amount associated with the order.                                           |
| Delivery             | Delivery charges associated with the order.                                     |
| Total                | Final order amount.                                                             |
| Return Shipping Fee  | Return shipping charges, where applicable.                                      |
| Delivery Information | Delivery contact channel and address.                                           |

### Order Actions

For the pending order shown, the following actions are available:

| **Action** | **Description**             |
| ---------- | --------------------------- |
| Confirm    | Confirm the selected order. |
| Cancel     | Cancel the selected order.  |

The available actions may depend on the order's current status.
