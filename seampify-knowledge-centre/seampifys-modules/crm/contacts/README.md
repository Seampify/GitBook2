# Contacts

The **Contacts** section serves as a centralized customer database where businesses can store, organize, manage, and access customer information.

## Contacts Overview

Navigate to **CRM → Contacts** to view your organization's contact database.

<figure><img src="../../../.gitbook/assets/Contacts (1).png" alt=""><figcaption></figcaption></figure>

The Contacts page provides the following features:

| **Feature** | **Description**                                                  |
| ----------- | ---------------------------------------------------------------- |
| Contacts    | View and manage individual customer records.                     |
| Lists       | Access contact lists for customer organization and segmentation. |
| Labels      | Manage labels used to categorize contacts.                       |
| Imports     | Access contact import functionality.                             |
| Export      | Export contact information.                                      |
| Add Contact | Manually create a new contact.                                   |
