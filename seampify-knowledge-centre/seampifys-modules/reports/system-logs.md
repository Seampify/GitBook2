# System Logs

The **System Logs** section provides a centralized activity history across communication channels, agents, and system components.

It allows users to review system records, monitor messaging activities, and access logs for different platform functions.

Navigate to **Reports → System Logs** to access this section.

<figure><img src="../../.gitbook/assets/system log.png" alt=""><figcaption></figcaption></figure>

## System Logs Categories

The System Logs page provides the following categories:

* Messages - View incoming and outgoing message records.
* Conversations - View conversation-related activity records.
* Export History - View records of export activities.
* Calls - View call-related activity records.
* Audit - View system audit records.
* REST API - View REST API activity logs.
* Agents - View agent-related activity records.
* AI Jobs - View AI job activity records.
* AI Agent Logs - View AI Agent activity records.
* Marketplace - View marketplace-related activity records.
* Imports - View import activity records

## Search and Filter Logs

Users can search and filter system logs using the available options.

| **Filter**   | **Description**                                                              |
| ------------ | ---------------------------------------------------------------------------- |
| Search       | Search message records using message content, contact name, or phone number. |
| From         | Select the starting date of the reporting period.                            |
| To           | Select the ending date of the reporting period.                              |
| All Channels | Filter records based on the communication channel.                           |
| All Types    | Filter records based on message type.                                        |
| Filter       | Apply the selected filtering conditions.                                     |
| Export       | Export the selected log records.                                             |
