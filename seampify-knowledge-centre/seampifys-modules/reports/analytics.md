# Analytics

The **Analytics Dashboard** allows businesses to monitor team performance and channel activities through key performance indicators, charts, and reports.

Navigate to **Reports → Analytics** to access the dashboard.

<figure><img src="../../.gitbook/assets/analytic (1).png" alt=""><figcaption></figcaption></figure>

## Analytics Filters

The Analytics Dashboard provides filtering options to customize the displayed information.

| **Filter**   | **Description**                                                        |
| ------------ | ---------------------------------------------------------------------- |
| All Channels | Filter analytics based on the selected communication channel.          |
| All Agents   | Filter agent-related analytics based on the selected agent.            |
| Date Range   | View analytics within a selected time period, such as the last 7 days. |

Available filters may vary depending on the selected analytics section.

***

## Channel Analytics

The **Channel Analytics** section provides an overview of messaging activities across connected communication channels.

<figure><img src="../../.gitbook/assets/analytic (1).png" alt=""><figcaption></figcaption></figure>

### Messaging Metrics

| **Metric**         | **Description**                         |
| ------------------ | --------------------------------------- |
| Incoming Messages  | Total messages received from customers. |
| Outgoing Messages  | Total messages sent to customers.       |
| Sent by Agents     | Messages sent by human agents.          |
| Sent by Automation | Messages sent through automation.       |
| Sent by Campaign   | Messages sent through campaigns.        |

The dashboard also displays percentage changes compared to the previous reporting period.

### Channel Analytics Charts

| **Chart**                       | **Description**                                                                               |
| ------------------------------- | --------------------------------------------------------------------------------------------- |
| Message Distribution by Channel | Displays the proportion of messages across communication channels.                            |
| Conversation Volume by Channel  | Compares the number of conversations across communication channels.                           |
| Channel-wise Message Breakdown  | Displays incoming, outgoing, agent, automation, and campaign message counts for each channel. |

***

## Conversations

The **Conversations** section provides insights into conversation activities and how customer enquiries are handled.

<figure><img src="../../.gitbook/assets/analytic (2).png" alt=""><figcaption></figcaption></figure>

### Conversation Metrics

| **Metric**            | **Description**                                                    |
| --------------------- | ------------------------------------------------------------------ |
| Total Conversations   | Total number of conversations recorded within the selected period. |
| Resolved              | Number of resolved conversations and their resolution rate.        |
| Active / Open         | Number of conversations currently open or active.                  |
| Handled by Automation | Percentage of conversations handled through automation.            |

### Conversation Analytics Charts

| **Chart**                       | **Description**                                                                                               |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Conversation Trends             | Displays created and resolved conversations over time.                                                        |
| Handled by Agents vs Automation | Compares the proportion of conversations handled by agents and automation.                                    |
| Response Metrics                | Displays average first response time, average response time, average resolution time, and average CSAT score. |

## Agent Performance

The **Agent Performance** section allows businesses to monitor individual agent productivity and conversation-handling performance.

<figure><img src="../../.gitbook/assets/analytic (3).png" alt=""><figcaption></figcaption></figure>

### Top Performer

The dashboard highlights the top-performing agent for the selected reporting period, including resolved conversations and first response time.

### Agent Performance Metrics

| **Metric**      | **Description**                                |
| --------------- | ---------------------------------------------- |
| Agent           | Agent name and availability status.            |
| Assigned        | Number of conversations assigned to the agent. |
| Resolved        | Number of conversations resolved by the agent. |
| Resolution Rate | Percentage of assigned conversations resolved. |
| First Response  | Time taken to provide the first response.      |
| Avg Response    | Average response time.                         |
| Avg Closing     | Average time taken to close conversations.     |
| CSAT            | Customer satisfaction score.                   |

### CSAT Score Comparison

Displays customer satisfaction ratings for agents during the selected reporting period.

## CRM & Sales

The **CRM & Sales** section provides an overview of lead management, deal performance, and task activities.

<figure><img src="../../.gitbook/assets/analytic (5).png" alt=""><figcaption></figcaption></figure>

### CRM Metrics

| **Metric**           | **Description**                                          |
| -------------------- | -------------------------------------------------------- |
| Total Pipeline Value | Combined monetary value associated with leads and deals. |
| Conversion Rate      | Percentage representing the CRM conversion rate.         |
| Avg Deal Value       | Average monetary value of closed deals.                  |
| Leads                | Total leads and closed leads.                            |
| Deals                | Total deals and closed deals.                            |
| Tasks                | Total tasks and completed tasks.                         |

### CRM & Sales Charts

| **Chart**        | **Description**                                                  |
| ---------------- | ---------------------------------------------------------------- |
| Lead Pipeline    | Displays the distribution of leads across lead stages.           |
| Deal Pipeline    | Displays deals according to their configured stages or outcomes. |
| Task Pipeline    | Displays task distribution.                                      |
| Conversion Trend | Displays new lead and won deal trends over time.                 |
| Leads Closed     | Displays closed lead activity by creation date.                  |
| Deals Closed     | Displays closed deal activity.                                   |
| Tasks Closed     | Displays completed task activity.                                |

{% hint style="info" %}
**Note:** Lead and Deal Pipeline stages are based on the stages configured under **Settings → CRM**. You can refer [here](../crm/#crm-stage-configuration).
{% endhint %}
