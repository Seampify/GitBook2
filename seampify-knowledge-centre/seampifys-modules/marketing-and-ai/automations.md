# Automations

The **Automations** section allows businesses to build no-code workflows to automate customer interactions and repetitive business processes.

<figure><img src="../../.gitbook/assets/auto (1).png" alt=""><figcaption></figcaption></figure>

## Automation Overview

| **Metric**         | **Description**                                      |
| ------------------ | ---------------------------------------------------- |
| Active Automations | Number of currently active automations.              |
| Total Runs (30d)   | Total automation executions within the last 30 days. |
| Success Rate       | Percentage of successful automation executions.      |
| Run Time (30d)     | Automation runtime recorded within the last 30 days. |

## How to Create an Automation

### Import from Library

The **Automation Library** provides pre-built automation templates that users can import based on their industry and business requirements.

#### Industry Categories

Users can browse automation templates based on the following industry categories:

* All Industries
* Healthcare
* Automotive
* Real Estate
* E-commerce
* Hospitality
* Education

Users can also use the **Search templates** search bar to locate a specific automation template.

#### Template Information

Each automation template displays the following information:

| **Field**       | **Description**                                              |
| --------------- | ------------------------------------------------------------ |
| Template Name   | Name of the automation template.                             |
| Description     | Brief explanation of the automation's purpose.               |
| Nodes           | Number of nodes included in the automation workflow.         |
| Uses            | Number of times the template has been used.                  |
| Rating          | Rating associated with the template.                         |
| Category        | The category associated with the automation.                 |
| Tags            | Key triggers, actions, or features included in the template. |
| Preview         | Preview the automation template before importing.            |
| Import Template | Import the selected template into your workspace.            |

#### Importing an Automation Template

1. Click **Import from Library**.
2. Select an industry category or search for a template.
3. Select your preferred automation template.
4. Click **Preview** to review the template, if required.
5. Click **Import Template** to import the automation.

### Create with AI

The **Create Automation with AI** feature allows users to generate an automation workflow by describing what they want the automation to perform.

#### Generating an Automation with AI

1. Navigate to **Marketing & AI → Automations**.
2. Click **Create with AI**.
3. Enter an automation name, if required.
4. Select the relevant communication channels.
5. Enter the priority order.
6. Describe your automation requirements.
7. Click **Generate** to generate the automation workflow.

<figure><img src="../../.gitbook/assets/auto (2).png" alt=""><figcaption></figcaption></figure>

#### Automation Configuration Fields

| **Field**          | **Description**                                                                          |
| ------------------ | ---------------------------------------------------------------------------------------- |
| Automation Name    | Enter a name for the automation. If left empty, AI will generate a name automatically.   |
| Channels           | Select the communication channels where the automation will be used.                     |
| Priority Order     | Specify the priority order of the automation.                                            |
| What should it do? | Describe the actions, conditions, and workflow requirements that the AI should generate. |

{% hint style="info" %}
**Note:** Review the AI-generated automation workflow and ensure it meets your business requirements before publishing it.
{% endhint %}
